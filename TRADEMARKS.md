# Trademark Policy

Spheradian's code is open source under the [Apache License, Version 2.0](LICENSE). The name **Spheradian** is not covered by that license: section 6 of the Apache License states that it grants no permission to use the licensor's trade names or marks. This policy explains how the name may be used.

The goal is simple: anyone who sees the name Spheradian should be able to trust that it refers to this project, or to software that faithfully represents it.

## Uses that need no permission

- **Talking about the project.** Articles, talks, tutorials, reviews, videos, and books may use the name to refer to Spheradian.
- **Distributing unmodified builds.** You may distribute Spheradian, built from an unmodified release or commit of this repository, under its own name. This includes Linux and BSD distribution packages. Changes needed only to build or integrate the package (paths, build flags, packaging metadata) do not count as modifications.
- **Stating compatibility.** You may say that your software "works with Spheradian", "is compatible with Spheradian", or "is a theme or extension for Spheradian", as long as it is accurate and does not suggest that the project endorses or maintains it.
- **Community use.** User groups, meetups, and community channels may use the name to describe what they are about, as long as they make clear that they are not official.

## Uses that need permission

- **Modified versions.** If you distribute a version with changes to its behavior, appearance, or security model, give it a different name. You may say that it is "based on Spheradian" or "a fork of Spheradian".
- **Product and company names.** Do not use Spheradian, or a confusingly similar name, as part of the name of a product, service, company, or domain.
- **Implied endorsement.** Do not present your product, service, or organization as official, certified, or endorsed by Spheradian unless it is.
- **Merchandise.** Selling items that carry the name requires permission.

## Why modified versions need a new name

Spheradian's isolation model depends on users trusting what the compositor shows them, such as the border that marks each window's trust domain. A modified build that carries the same name could weaken those guarantees while appearing to be the real thing. A different name keeps that distinction clear.

## Asking for permission

Open an issue in this repository describing what you would like to do, or contact the maintainers. When in doubt, ask: most requests in good faith will be granted.

## Status of the mark

Registration of the Spheradian name is being pursued. This policy applies regardless of registration status and may be updated as that process advances.
