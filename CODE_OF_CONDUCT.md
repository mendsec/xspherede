# Code of Conduct

XSphereDE adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to all project spaces, including issues, pull requests, discussions, and any other channel used to represent the project.

## In short

- Be respectful and assume good faith.
- Criticize code and ideas, not people.
- Harassment, discrimination, personal attacks, and publishing others' private information are not tolerated.
- Keep technical disagreement technical. Strong opinions about security design are welcome; hostility is not.

## Reporting

Report unacceptable behavior to the maintainers at **fabiomendes@mailfence.com**. Reports are handled confidentially. Maintainers may remove content, or warn, temporarily restrict, or ban participants, following the enforcement guidelines of the Contributor Covenant.
