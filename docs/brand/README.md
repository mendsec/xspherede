# Spheradian logo

A wireframe sphere with the viewer at its center. A curved window sits on the
surface, and dashed lines run from the viewer to its corners: the solid angle,
in steradians, that the window takes up, which is where the name comes from.
The three windows use the trust-domain colors from `src/security.rs`:
emerald (`TRUSTED`), cyan (`SANDBOX`), and violet (`CORE-VAULT`).

| File | Use |
| --- | --- |
| `spheradian-logo.svg`, `-512.png`, `-1024.png` | Main mark on a dark background (GitHub org avatar) |
| `spheradian-logo-small.svg`, `-small-256.png` | Simplified mark for favicons and sizes under 64 px |
| `spheradian-logo-transparent.svg`, `-1024.png` | No background, for dark surfaces |
| `spheradian-logo-light.svg`, `-1024.png` | No background, darker green for light surfaces |

The SVGs are generated by `generate_logo.py`. Edit the script rather than the
SVGs, then run `python3 docs/brand/generate_logo.py`. The PNGs are rendered
from the SVGs.
