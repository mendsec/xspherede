This is the v0.0.1 prototype itself, compiled from the same Rust and wgpu code to WebAssembly. At startup it uses WebGPU if your browser provides a working WebGPU adapter, and WebGL2 otherwise. It needs a mouse and keyboard. The host security audit (F12) shows n/a here, because a browser page cannot read kernel settings.
